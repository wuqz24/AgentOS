## 真实模型最后验收

1. 在 host/local.env 配置可用 Base URL、模型名和本地密钥。
2. 执行 `python scripts/accept_model.py`，保留 API 模式与模型名。
3. 核对至少两次进程采样、文件检索、实际返回到下一轮输入、有效Context证据引用。
4. 人工核对最终文本中的PID、状态、运行量和原因推断；不能仅因输出了自然语言就通过。
5. 再验一次服务错误或任务取消后恢复，记录模型耗时与内核耗时的不同口径。
6. 更新B03/B04/E01、实施进展和结题材料。当前没有这一真实模型通过记录。
